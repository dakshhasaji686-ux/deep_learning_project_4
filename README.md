## Project Overview
This project focuses on building and evaluating Convolutional Neural Networks (CNNs) using the CIFAR-10 dataset for image classification.

The project explores CNN architectures, convolution operations, pooling, data augmentation and transfer learning using MobileNetV2.

## Dataset – CIFAR-10
- Total Images: 60,000
- Training Images: 50,000
- Testing Images: 10,000
- Image Size: 32 × 32 pixels
- Colour Channels: RGB
- Classes: 10

**Classes:** Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship and Truck.

The dataset is available directly through TensorFlow/Keras.
